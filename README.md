# Student Record Management System (Java)

A beginner-friendly, menu-driven console application.

## Features
- Add students with name, roll number, and marks
- View all student records
- Search by roll number
- Update a student's name or marks
- Delete a student record
- Calculate grade and percentage (marks are out of 100)
- Validate input and prevent duplicate roll numbers

## Java concepts
Classes and objects, encapsulation, ArrayList, methods, loops, switch, if-else, Scanner, and input validation.

## Run
Requires Java JDK 8 or later.

```bash
javac Main.java
java Main
```

You can also paste `Main.java` into an online Java compiler that supports console input.

**Note:** Records are stored in memory and are cleared when the program exits. File/database storage can be added in a future version.
